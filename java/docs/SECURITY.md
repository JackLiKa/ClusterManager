# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a vulnerability

If you discover a security vulnerability in MQCluster, please report it privately so we can fix it before public disclosure.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please contact the maintainers directly:

- GitHub: [JackLiKa](https://github.com/JackLiKa)

Include the following details if possible:

- A description of the vulnerability.
- Steps to reproduce or a proof of concept.
- The affected version(s).
- Any suggested remediation.

We will acknowledge receipt within 48 hours and aim to provide a resolution timeline as soon as we have assessed the issue.
